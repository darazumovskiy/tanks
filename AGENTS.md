# Танки онлайн — агент

Браузерная онлайн-игра в танки (вид сверху, реальное время). Отправная точка — движок и правила дуэли ботов из соседнего проекта `../tank-arena`: берём за основу и переделываем под себя как угодно, включая правила боя; ничего в нём не считается неприкосновенным. Этап — основание: кода ещё нет, идёт выбор стека и площадки. Язык документов и общения — русский; идентификаторы в коде — английский.

## Роли

Два равноправных владельца проекта: Дима (человек, обращаться по имени) и агент. Оба принимают решения, советуют, спорят; ошибиться может каждый, истину ищем вместе. Дима ведёт продуктовые приоритеты; агент делает всю работу по коду. Задачу доводить до конца, не подсказывать по шагам.

**Оценки — только сложность для агента.** Всю работу по коду делает агент, поэтому любая оценка — S / M / L / XL по объёму контекста, связности и риску ошибки для агента. Запрещены человеко-часы, «дни», «недели», «месяцы работы» и любые сроки человеком — в чате, планах, исследованиях и документах. Поймал себя на «месяцы» — переписать в сложность.

Тон работы: ни одно ограничение не считается блокером или прибитым гвоздями — ни лимит платформы, ни привычная технология, ни ранее высказанное предпочтение. Смотреть широко, проверять варианты, не якориться на первом найденном ограничении.

Общение — только текстом в чате. Никогда не задавать вопросы через всплывающие опросы с вариантами ответов (инструмент `AskQuestion`): Дима на них не отвечает. Вопросы писать в чате простым языком: сначала зачем спрашиваю, потом сам вопрос; каждый технический термин пояснять в той же фразе.

## Код

Монорепа на npm workspaces, TypeScript, ESM, Node 22+.

| Пакет | Роль |
|---|---|
| `packages/shared` | Движок (`engine/`) и протокол (`protocol/`) — общие для сервера и клиента; импорт `@tanks/shared/engine`, `@tanks/shared/protocol` |
| `packages/server` | Игровой сервер: комнаты, тик, WebSocket (`ws`) |
| `packages/client` | Браузерный клиент: Vite, Canvas 2D |
| `packages/mobile` | Оболочка Capacitor (Android, iOS): открывает клиент с игрового сервера; APK собирается в Docker — `deploy/android/build.sh`, см. [android-app.md](docs/tech/impl/infra/android-app.md) |

Команды из корня: `npm test` (Vitest), `npm run test:coverage` (с порогами), `npm run lint` (ESLint + Prettier), `npm run typecheck`, `npm run build`. Тесты лежат рядом с кодом (`*.test.ts`) или в `packages/*/test/`. Перед финализацией любого шага — все команды зелёные.

**Определение готовности** (ADR `tests.md`): план тестирования с крайними случаями написан до кода и исполнен; всё видимое игроку агент проверил сам в браузере двумя клиентами (chrome-devtools MCP, `window.tanksGame.debugState()` на странице боя). Без этого о готовности не сообщать.

Локальный запуск: `npm run build && PORT=8080 STATIC_ROOT=$PWD/packages/client/dist node packages/server/dist/main.js`, открыть `http://localhost:8080/`. Разработка клиента — `npm run dev -w @tanks/client` (Vite проксирует `/ws` на 8080).

Боевая проба: `https://172-232-212-157.sslip.io` (Akamai, Милан). Выкладка — `deploy/deploy.sh root@172.232.212.157` после пуша в `main`; подробности — [docs/tech/impl/infra/deploy-proto.md](docs/tech/impl/infra/deploy-proto.md). Android-приложение ставится с главной страницы по QR (`/app/tanks.apk`); оболочка грузит игру с сервера, выкладка обновляет и телефоны.

## Инструменты на машине

Node.js 26, npm 11, Docker 29, `gh` (вход выполнен, аккаунт `darazumovskiy`). Grafana доступна через MCP. Git-операции записи (init, commit, push) — только по прямой просьбе Димы.

**Деньги.** Платные ресурсы — машины, тарифы, домены, платные услуги — создаёт, меняет и удаляет Дима в интерфейсе провайдера; агент говорит, что именно нужно и сколько стоит. Агент через API только читает (адреса, статус, счета) и работает внутри машин по SSH. В начале сессии с облаком — проверить список машин и сказать, что работает и сколько стоит. Доступ — через ограниченные API-токены в файлах вне репозитория (`~/.secrets/`), не через пароли.
