# Разворот на телефоне: разбор журнала 7PSX

Игра `7PSX` (2026-10-04 14:00, бот уровня 1, телефон, флаги `quickreverse=1 guard=1 aimline=1`), первые 31 с. Дима пять раз пытался развернуть танк; три попытки сорвались в задний ход с рывком в обратную сторону, одна прошла по дуге, одна — почти остановкой с доворотом. Журнал — `/opt/tanks-logs/7PSX.log`; восстановление направления стика из команды: газ = cos(угол между стиком и курсом), знак — из поворота, в заднем ходу угол от кормы.

## Как Дима водит стик

Палец не ставится в нужную сторону, а **ведётся по кольцу стика**, как по рулю: 5–30° за тик (150–900°/с), пока танк не повернётся. Корпус поворачивает не быстрее 2,55 рад/с (146°/с, 4,9° за тик) — палец уходит вперёд корпуса, за 0,3–0,5 с разрыв достигает 90°.

## Что делает алгоритм

`steerHull` (`packages/client/src/steering.ts`): направление стика — желаемый курс; газ = cos(расхождение); при расхождении больше 90° (`hasQuickReverse`) — задний ход, расхождение считается от кормы, знак поворота **меняется на противоположный**.

Три сорванные попытки — одинаковый сценарий:

| 0:07,0 | Курс −144°, стик за 0,2 с уходит на +100° (на 116° вперёд). Газ падает 1,0 → 0,06, танк поворачивает влево |
| 0:07,2 | Разрыв 92° → задний ход. Поворот скачком −1 → +1 (рывок вправо на 3 тика), скорость +89 → −103 |
| 0:07,3–0:08,4 | Палец идёт дальше по кольцу до −175°; танк задним ходом крутится влево на 160° (курс −164° → +36°), уезжая назад на 48 ед. |

| 0:09,0–0:09,7 | Выход из заднего хода (разрыв < 70°), ещё один скачок знака поворота; вперёд с доворотом до −168° |

Итог: 2,7 с, танк повернул на 160° влево и на 270° вправо, уехал назад на 90 ед. и встал в 24° от исходного курса. Попытки 0:11,4–0:16,8 (5,4 с, итог 168° → 156°, дважды влетал в задний ход) и 0:24,0–0:26,3 (2,3 с, −44° → −64°) — то же.

Две прошедшие попытки — когда разрыв палец–корпус не перевалил за 90°:

- 0:19,1–0:20,6: разрыв дошёл до 89° (газ 0,01), танк почти встал, довернул на 160° за 1,5 с и разогнался. Удачно, но медленно.

## Выводы

1. Направление стика позади корпуса читается как «ехать назад», поэтому разворот — самый частый манёвр боя — стиком выразить невозможно: он всегда превращается в задний ход.
2. Задний ход меняет знак поворота: танк дёргается в сторону, обратную движению пальца, и скорость падает на ~280 ед./с (с +176 до −106). Это и есть «задний ход = смерть» против бота 7+.
3. Порог 90° (`hasQuickReverse`) делает срыв чаще, чем прежние 110°: палец Димы обгоняет корпус на 90° за треть секунды.
4. Газ = cos(расхождение) слишком мягок для крутого поворота: при разрыве 45° газ 0,7 — танк едет дугой вместо пируэта.
5. Задний ход в бою Диме нужен только намеренно; срабатывание по углу стика — всегда случайность.
