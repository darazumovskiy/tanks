1. **Дневной повтор замера VPS / Cloudflare** — сопутствующее, из задачи bootstrap; машины Akamai живы до него. После него парижская удаляется, миланская становится сервером пробы.
2. **Коммиты.** Агент делает коммиты и пуши только по команде Димы; предложение — разрешить коммит по завершении каждого шага плана.
3. **Код-стайл TypeScript.** ADR `code-style.md` пока без языковых правил; агент предложит дополнение после первого кода.
