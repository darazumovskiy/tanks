## Сделано

- Шаг 1: git инициализирован, remote `origin` → GitHub; монорепа `packages/{shared,server,client}`, TypeScript strict, Vitest 5, ESLint (strict + stylistic type-checked), Prettier, Vite 7, `ws`. Коммит `c70cb9d`.
- Шаг 2: движок в `packages/shared/src/engine/` (`constants`, `stats`, `geometry`, `maps`, `round`, `view`), правила без изменений, поля переименованы под код-стайл (`isAlive`, `hasBounced`, `isFiring`). Эталон — `test/determinism/`: генератор гоняет оригинальный `engine.js` по шести сценариям (четыре карты, бой без стрельбы с зоной, бой с редкой стрельбой), хеш состояния на каждом тике; тест повторяет сценарии на новом движке — 9459 тиков совпали побитово. Перегенерация эталона: `node packages/shared/test/determinism/generate.mjs ../tank-arena/kit/arena/engine.js`. Коммит `49ace04`.

- Шаг 3: протокол (`packages/shared/src/protocol/`) — 9 типов сообщений, бинарный кодек, квантование осей 1/127, тесты туда-обратно и на мусор. Коммит `1543fdb`. Документ — `tech/impl/backend/protocol.md`.
- Шаг 4: сервер — комнаты по коду, фазы раунда, «новое пересиливает старое» для ввода, снимки с `ackSeq`, раздача клиента, `/healthz`; интеграционные тесты через WebSocket, включая полный раунд двумя скриптовыми игроками; пороги покрытия. Коммит `694ca52`. Документ — `tech/impl/backend/duel-server.md`.
- Шаг 5: клиент — `/` и `/d/<код>`, предсказание с переигрыванием, интерполяция чужого, ввод клавиатура + мышь, рендер, HUD. Проверено в двух вкладках локально. Коммит `8fd496d`. Документ — `tech/impl/frontend/duel-client.md`.
- Шаг 6: деплой — Caddy с сертификатом Let's Encrypt на `172-232-212-157.sslip.io`, systemd, скрипты `deploy/`. Дуэль проверена из офиса через боевой сервер. Коммит `1f50b22`. Документ — `tech/impl/infra/deploy-proto.md`.

- Шаг 7, первая игра Димы: сеть — «задержки не вижу». Замечания: оформление было черновым — перенесено из `tank-arena` целиком (пол, спрайты, эффекты, панели, объявления, звук); двойной вылет снаряда у стреляющего — причина: свой снаряд после подтверждения сервера рисовался из снимков с отставанием интерполяции; исправлено — свои снаряды всегда из предсказания. Протокол v2: события снимка несут направление и признаки. Проверено на боевом сервере: число снарядов при подтверждении не прыгает. Коммит `e63deb4`.

## Блокеры и открытые вопросы

1. **Дневной повтор замера VPS / Cloudflare** — сопутствующее, из задачи bootstrap; машины Akamai живы до него. После него парижская удаляется, миланская становится сервером пробы.
2. **Покрытие сервера 92 %, не 100 % по ADR.** Непокрыто: события долгого раунда (появление аптечки, подбор, зона), защитные ветки на невозможные состояния. Решить: добавить длинный раунд в тесты или переписать защитные ветки так, чтобы их не было.
3. **Выброс при уходе соперника.** Снимки прекращаются, экран ждёт; переподключение по той же ссылке работает, но локальный счёт и раунд сбрасываются — ожидаемо для пробы.
