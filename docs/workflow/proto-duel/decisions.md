# Решения

Только подтверждённые обоими владельцами. Дата, что решили, что это меняет.

## 2026-10-02

- **Задача — проба: сервер с сокетом, браузерный и Android-клиент, дуэль 1 на 1 по ссылке.** Дима играет сам с собой. Меняет: этап 1 плана-карты сужен до дуэли; движок берётся из `tank-arena` без обобщения на N танков.
- **Площадка пробы — машина `tanks-echo-mil` (Akamai, Милан, $5/мес).** Парижская удаляется после дневного замера.
- **Репозиторий — `github.com/darazumovskiy/tanks`**, публичный, создан Димой. Монорепа: `packages/shared` (движок, протокол), `packages/server`, `packages/client`.
- **Транспорт пробы — WebSocket.** Слой транспорта изолирован от игровой логики для будущей замены.
- **Android — настоящее приложение, отдельным этапом.** Не браузер на телефоне. Этап включает выбор технологии, сборку и способ установки на телефон Димы без магазина. Начинается после рабочей браузерной дуэли.
- **Коммиты и пуши — по завершении каждого шага плана**, без отдельного вопроса. Промежуточные коммиты внутри шага — на усмотрение агента.
- **Почта в git для этого репозитория — `darazumovsky@gmail.com`** (почта GitHub-аккаунта).
- **Код-стайл TypeScript вписан в ADR `code-style.md`:** Prettier, strict без `any`, булевы условия, префиксы булевых, без вложенных тернарников, ESM с расширениями, тесты рядом.
- **План тестирования — до кода, сквозная проверка — агентом в браузере** (2026-10-02, после бага со счётчиком команд между раундами). Для каждой фичи: сценарии и крайние случаи по трём слоям — сервер, клиент, сквозной прогон; исполняется до объявления готовности. ADR `tests.md`, шаблон документа фичи в `tech/impl/README.md`.
- **Порядок работ:** шаги «репозиторий → движок → протокол → сервер → браузерный клиент → деплой» делаются одним блоком с проверкой на каждом шаге; мобильное приложение — после.
