# Видимые элементы боя толпы — что проработать визуалом

Список для визуальных сессий по скиллу `visual-iteration`. Шаг 7 делает логику каждого элемента с черновым видом продуктового качества: шрифты Russo One и Inter, тёмная палитра, акцент `#e8825a`, выверенные отступы, состояния кнопок, плавные переходы, проверка глазами на экране телефона. Визуальные сессии идут после боевой пробы, первыми — элементы, которые проба покажет слабыми; каждая доводит вид: бриф → лаборатория `/?lab=fx` → раунды вариантов → критик → выбор по странице просмотра → токен. Правила — `adr/visual.md`, язык — `tech/base/visual-language.md`. Источник смысла элементов — `concept/ffa.md`.

Полоса — полоса яркости из `visual-language.md`: телеграф (предупреждает), удар (событие), статус (спокойная информация), фон.

## Порядок визуальных сессий

1. Ник и отметка ботов, неуязвимость, подбитый танк — их видно в каждом кадре боя.
2. Табло, лента убийств, свой фраг, «тебя убил» и ожидание возрождения — главный поток событий матча.
3. Стрелки у края, линия «на нём», зона, предупреждение о финале — телеграфы, спорят друг с другом за внимание; проверять вместе в одной сцене.
4. Лобби, отсчёт, итоги, зритель — экраны вокруг боя.
5. Вход на главной, «Ты тут?», выкидывание, занято, обрыв связи.
6. Карта толпы и мини-игра — вместе с шагами 8 и визуала карт.
