# Части шага 7 — вводные для исполнителей

Договор — [ffa-client.md](../../../tech/impl/frontend/ffa-client.md); номера пунктов плана тестирования — оттуда. Исполнитель читает AGENTS.md, `docs/adr/*.md`, `ffa-client.md` целиком и свою строку ниже. Общее для всех частей: план тестирования уже написан — исполняется; каждый новый тест ловит подменённую поломку, исполнитель показывает падение; новые модули без браузера вносятся в `vitest.config.ts` с порогами (раздел «Покрытие» договора); после правки `shared` — `npm run typecheck`; готовность — `npm run lint`, `npm run typecheck`, `npm test`, `npm run test:coverage`, `npm run test:e2e` зелёные; не коммитить; отчёт — что сделано, какие пункты исполнены, что подменял, файлы, расхождения с документом.
