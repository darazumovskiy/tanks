## На подтверждение Диме

Продуктовые решения, принятые агентом ночью, чтобы не останавливать работу; в `decisions.md` — после «ок» Димы.

- Вход: `/ffa` — игра на 30, кнопка «В общий бой» на главной ведёт туда; игры на 10 и 50 — только по прямым ссылкам `/ffa/10`, `/ffa/50`.
- Главная: секция «Общий бой» — первой из действий, кнопка оформлена основным действием.
- Итоги: эффективность называется «Польза» («×1,4», без урона — «—»).
- Цвета в толпе: свой танк и свои снаряды — акцент `#e8825a`, все чужие — `#4fc3c9`; бот — цвет чужого и отметка «БОТ» перед ником.
- Тексты экранов — черновик из `ffa-client.md`, «Тексты для игрока».
- Кнопка называется «В общий бой» (в концепте было «В бой» — так уже называется кнопка боя с ботом).
- Ссылки `/ffa` открываются в браузере, не в приложении: фильтр ссылок приложения знает только `/d/`, а новая сборка APK в эту задачу не входит.
- «Выйти» из боя закрывает соединение: место и стоящий танк держатся 15 с, как при обрыве.
- Камера на компьютере с мышью: сдвиг в сторону курсора растёт с его расстоянием от центра экрана (курсор у центра — танк в центре, у края — полный сдвиг); на телефоне — полный сдвиг по башне. Иначе прицел мышью по близкой цели впереди разворачивает башню назад.

Готовность части: план тестирования части исполнен; `npm test`, `npm run test:coverage`, `npm run lint`, `npm run typecheck`, `npm run test:e2e` зелёные; видимое проверено в браузере двумя клиентами и снимками в размере телефона. Вид — черновой продуктового качества (см. «План»), без раундов вариантов: каждый элемент доводится потом своей визуальной сессией (шаг 9). Бой с ботами для проверок — `npm run swarm`.

Прочитать перед 7a:
- что видит игрок и правила боя — `concept/ffa.md`; решения задачи — `decisions.md`;
- сообщения общей игры, порядок сообщений вошедшему, снаряды разницей — `tech/impl/backend/ffa-server.md`, `knowledge/exchange-review.md` («Проверено и надёжно», «Отложено»: ушедший пропадает из итоговой таблицы, его номер остаётся в `killerId` — держать имена ушедших для ленты);
- предсказание своего танка по неподтверждённым командам (`ackSeq`), окно обзора, рой для проверок — `crowd-bots.md`, `swarm.md`;
- клиент дуэли — `tech/base/frontend.md`, `tech/impl/frontend/duel-client.md`, `duel-camera.md`, `touch-controls.md`, `aim-line.md`, `e2e-stand.md`; где клиент рассчитан на двоих — `knowledge/duel-assumptions.md`;
- что прорабатывать визуалом и какие состояния нужны лаборатории — `knowledge/visual-elements.md`.

Решить в 7a: как вход в общую игру уживается на главной с боем против бота — кнопка ведёт в игру на 30 мест, игры на 10 и 50 доступны другим путём (решение 2026-10-05, ~04:33); как предсказание своего танка обходится со столкновениями с чужими танками, которые клиент видит в прошлом; как устроены куски пола большой карты. Пол уже процедурный (`render/floor.ts`: генератор с сидом), но заготавливается одной картинкой на всё поле в двойном разрешении — на карте 50 это ~10400 × 5800 точек, около 240 МБ, телефон такой холст не создаст. Генератор переписывается так, чтобы каждая деталь зависела от своего места, а не от порядка вызовов: тогда любой кусок рисуется сам по себе и стыкуется с соседями без шва; в памяти — только куски вокруг окна обзора.

Рамка видимости, ужатие чисел и противодавление с полной пересылкой снарядов — после сдачи: для проб трафик не мешает (квота машины — ~140 часов игры на 30 в месяц). Клиент шага 7 строится так, чтобы танки могли появляться в снимке и пропадать из него — рамка видимости его не перепишет. Урон из-за экрана ~20 %; снаряд виден на экране до попадания 0,65–1,6 с в зависимости от пушки, со стороны спины при камере со сдвигом — меньше. Дальность снаряда пока не трогаем, смотрим в пробе. Отложенное из проверки — `knowledge/exchange-review.md`, «Отложено». На картах 30 и 50 мало укрытий (21 и 22 стены: точки возрождения и аптечки занимают целые клетки) — к шагу визуала карт.

Заметка к шагу 7: клиент пока умеет только дуэль, входа в общую игру на главной нет. Тех-дизайн и план тестирования клиента — `tech/impl/frontend/`, до кода. `Error Replaced` и `Error Idle` — окончательные, без автоматического переподключения; переподключение после обрыва — с пропуском из `FfaWelcome`, номера команд — с единицы; окно обзора `FFA.viewWidth` × `FFA.viewHeight` — вокруг точки, за которой следит камера (свой танк со сдвигом по башне), экран не показывает дальше него; боты пока считают окно по центру танка (`crowd/view.ts`) и переходят на сдвиг клиента в части 7e. Устройства: телефон Димы (Xiaomi, USB-отладка) и эмулятор Android подключены к `adb`.
