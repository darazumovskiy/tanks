Выложено 2026-10-04 (коммит `273bc3c`, `deploy/deploy.sh`): игра слушает `127.0.0.1:8080` (снаружи порт закрыт, `/metrics` через Caddy — 404), Vector читает `/metrics`, панели игры на дашборде заполняются. Остановка Vector посреди дуэли с манекеном (15 с) на игру не повлияла: rtt 50–53 мс, 30 тиков/с, поправок 0.

Задержка цикла событий меряется своим таймером с шагом 10 мс: `perf_hooks.monitorEventLoopDelay` после `reset()` теряет блокировку, случившуюся сразу за сбросом.
