# Решения

Только подтверждённые обоими владельцами. Дата, что решили, что это меняет.

## 2026-10-01

- **Отправная точка — `tank-arena`.** Движок и правила боя берутся из соседнего проекта как основа, переделываются свободно — вплоть до переписывания. Меняет: концепт боя стартует с этой физики и характеристик; аудит движка — первый шаг.
- **MVP — «сыграть в офисе».** Комната на 10–50 человек по ссылке, вход через Google. Направления «бой с ботами» и «ладдер» — после. Меняет: план-карта, границы MVP.
- **Приоритет техники — скорость отклика.** Все технологические решения оцениваются сначала по отклику. Меняет: критерии выбора транспорта, сервера, площадки.
- **Сервер авторитарен, валидация на бэкенде.** Записано в ADR `architecture.md`.
- **База — браузер, мобильные через браузер.** Нативные обёртки — позже. Меняет: требования к клиенту, сенсорный ввод в MVP.
- **Код — в GitHub.** ADR `process.md`.
- **Хранение — MySQL и Redis** как предпочтение оператора; подтверждается при выборе площадки.
- **Античит — не в первой итерации.**
- **Оценки сложности и сроков — на агенте**, в единицах сложности для агента. ADR `process.md`.
- **Структура базы знаний:** концепт / тех-дизайн (базовый и реализаций, по областям бэк-фронт-инфра) / ADR / исследования / workflow. Формат ADR — из `hw-all`. Скилл `current-task` — из `hw-all`.
- **Права на движок `tank-arena` закрыты.** Автор (PashaGanson) в переписке 2026-10-01 дал согласие на использование, оформлять лицензию не будет. Запасной путь — переписать движок по `kit/ARENA.md`, он тривиален. Меняет: перенос кода не блокирован.
- **Равноправные владельцы.** Люди команды и агент — владельцы проекта: принимают решения, советуют, оспаривают друг друга. ADR `process.md`, `AGENTS.md`.
- **Ограничение — не блокер.** Лимиты платформ и привычные технологии — вводные, не причины отбрасывать варианты. Хранилище и транспорт — за прослойками, технологии заменяемы. Меняет: «MySQL + Redis» — предпочтение, не требование; SQLite-подобные и key-value базы облаков допустимы. ADR `process.md`.
- **Хостинг — серьёзное исследование, без предрешённого ответа.** География игроков (Европа и Америка) — ключевой критерий; своя машина в одном месте этому не отвечает. Cloudflare Durable Objects — полигон для замера, не отброшен. Исследование — `research/hosting.md`.
- **Транспорт — отдельное исследование** с замерами на реальных сетях. `research/transport.md`.
- **Язык сервера — TypeScript на Node.js**, один движок на сервере и клиенте. Вопрос масштабирования на много комнат и регионов закрывается замером (раздел в `research/realtime-stack.md`).
- **Тесты — ADR `tests.md`:** бэкенд только интеграционными через свои точки входа с покрытием 100 %, без юнитов; фронтенд — интеграционные (определение границы — при проектировании клиента); сквозные в настоящем браузере; нагрузочные.
- **Мониторинг — ClickHouse.** Стек Vector → ClickHouse → Grafana по образцу `hw-all`. `tech/base/infra.md`.
- **Управление человеком:** десктоп — WASD + мышь на башню; мобильный — два джойстика и кнопка выстрела. `concept/office-match.md`.
- **Клиент:** Canvas 2D как в `tank-arena`, маленькая библиотека компонентов для интерфейса вокруг боя, Vite. `tech/base/frontend.md`.
- **Режим боя MVP** в общих чертах — deathmatch с возрождением на время; детали боя, режимов и возрождения — отдельный гейм-дизайн.
- **Матчмейкинг** нужен как отдельный концепт.
- **Репозиторий и git** — когда появится первый код.
- **Клиент-серверная модель закреплена в ADR `architecture.md`:** клиент предсказывает свой танк и не ждёт подтверждения; чужих интерполирует; движок и соединения комнаты — в одном процессе без блокирующих операций в тике; проверки, не влияющие на исход боя, — вне тика.
- **Порядок этапов: сначала прототип для двоих.** Выбрать хостинг и собрать простейший бой без лобби и авторизации, который тестируется с компьютера и Android-телефона. Только потом — MVP для офиса. Меняет: план-карта, этап 1.
- **Замер на VPS — Akamai (Linode):** есть и Милан (`it-mil`), и Париж (`fr-par`) в одном аккаунте, почасовая оплата, минимальная машина $0,0075/час; новому аккаунту дают стартовый кредит. Оператор создаёт аккаунт и две машины, агент даёт эхо-сервер и инструкцию.
- **Платные ресурсы создаёт и удаляет оператор**, агент — только чтение через API и работа внутри машин. `AGENTS.md`.
- **Цена хостинга — предсказуемая месячная**, постоянно работающий сервер, ориентир до €100–200/мес. Критерий в `research/hosting.md`.
- **Следующая задача — `proto-duel`** (2026-10-02): проба «сервер с сокетом + браузерный и Android-клиент + дуэль 1 на 1 по ссылке». Этап bootstrap закрыт по основным вопросам; незакрытые (дневной замер, исследование транспорта) переходят в состояние новой задачи.
- **География MVP — офис на Кипре.** Площадку искать по минимальной задержке до Кипра среди ближайших европейских регионов; локальных кипрских хостингов, которые бы подошли, не ожидается. Америка — критерий для следующих этапов. Меняет: точки замеров в `research/hosting.md`.
