# Решения

**2026-10-05.** Пишем постоянный номер устройства и IP каждого игрока: без них по журналам не понять, сколько было разных людей.

**2026-10-05.** Сверх номера и IP собираем всё, что браузер и адрес отдают без вопросов игроку: страна, город и провайдер по IP из офлайн-базы, язык, часовой пояс, модель, железо, связь, источник прихода (метка `?from=` в ссылке и страница, с которой пришли). Точной геолокации, которая требует разрешения системным окном, нет.

**2026-10-05.** Полный профиль — один раз на открытие страницы (главная или страница боя), в бою — только номер устройства в строке `device`. Визиты хранятся 90 дней, журналы игр — по-прежнему 7.

**2026-10-05.** Игроку показываем, что собираем: короткий текст под иконкой подсказки на главной, вместе с упоминанием DB-IP по лицензии базы.

**2026-10-07.** Пояснение игроку — простейшая плашка внизу главной: крестик закрывает её, и на этом устройстве она больше не показывается. К продукту она отношения не имеет, поэтому визуальный цикл с вариантами для неё не проводится — оформление взято у плашки «Открыть в приложении».

**2026-10-07.** Работа ведётся в отдельной рабочей папке `../tanks-visitors` на ветке `visitors` от `main`; в `main` — после проверки.
