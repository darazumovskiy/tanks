# Код-стайл

Именование, читаемость, комментарии. Правила не зависят от языка; после выбора стека файл дополняется форматированием и идиомами конкретного языка.

---

## Ранние выходы вместо вложенности
Условия отказа — наверху функции отдельными `if` с `return` / `continue` / `throw`. Основная ветка идёт плоско, без отступов. Тернарный оператор — только для выбора простого значения; любая логика внутри веток — отдельный `if`.

## Простые условия
Цепочка из трёх и более проверок разбивается на именованные булевы переменные. Булевы имена — утвердительные (`isAlive`, `hasTarget`), без `not` и двойных отрицаний.

## Строгое сравнение
Только строгое равенство (`===` или аналог языка). `null`/`undefined` проверяются явно, не через истинность объекта.

## Без магических строк и чисел
Типы, ключи, идентификаторы, физические константы — именованные константы рядом с кодом, который ими владеет. Константы одного смысла — в одном месте с общим префиксом.

## Не писать неиспользуемый код
Поле, метод, константа, экспорт существуют только если используются. Ничего «на будущее» и «на всякий случай».

## Имена без роли потребителя
Функция описывает операцию или данные, а не того, кто её вызывает. Суффиксы `forClient`, `forBot`, `forAdmin` запрещены; различие поведения — явным параметром или отдельной функцией с доменным именем.

## Комментарии — только смысловые
Разрешён комментарий, который объясняет неочевидное намерение или ограничение, которого код сам не передаёт. Запрещены: пересказ кода, история правок («было/стало», «перенесено из»), ссылки на документы и задачи, параграфы спецификации.

## Один язык текста
Код (идентификаторы) — английский. Комментарии, документация, тексты интерфейса — русский.

## TypeScript

### Форматирование — Prettier
Одинарные кавычки, строка до 120 символов, висячие запятые. Форматирование не обсуждается в ревью: `npm run format`.

### Строгий режим без `any`
`strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`. `any` запрещён; неизвестное снаружи — `unknown` с явной проверкой. У каждой функции — явный тип возвращаемого значения.

### Условия — только булевы
В `if`, `while`, `&&`, `||`, `?:` — только значения типа `boolean`. Не `if (list.length)`, а `if (list.length > 0)`; не `if (name)`, а `if (name !== '')` или `!== undefined`.

### Булевы имена с префиксом
Переменные и поля типа `boolean` — `is*`, `has*`, `can*`, `should*`.

### Без вложенных тернарников
Тернарник одного уровня для выбора простого значения; остальное — `if`.

### Модули — ESM, импорты с расширением
`import { x } from './file.js'` в коде пакетов `shared`, `bots` и `server` (NodeNext); между пакетами — через имена `@tanks/shared/engine`, `@tanks/shared/protocol`, `@tanks/bots`.

### Тесты рядом с кодом
`*.test.ts` рядом с проверяемым модулем; большие эталонные данные — в `packages/<пакет>/test/`.
