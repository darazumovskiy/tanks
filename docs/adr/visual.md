# Визуал

Как видимый игроку элемент доводится до продуктовой картинки: сам агент по визуальному языку, а по прямому указанию оператора — визуальный цикл с лабораторией, вариантами и выбором по контактному листу.

---

## Визуальный цикл — по указанию оператора
Визуальный цикл (скилл `visual-iteration`) запускается только по прямому указанию оператора — «сделай сочно», «переделай вид», «визуал для X». Без указания агент оформляет элемент сам по [visual-language.md](../tech/base/visual-language.md), проверяет его по снимку экрана телефона и компьютера («Проверка по скриншоту» там же) и в бою двумя клиентами; вариантов, контактных листов и выбора оператора нет.

## Логика отдельно, картинка отдельно
Логика элемента — состояние, геометрия, тесты — не зависит от вида и принимается отдельно. Вид не меняет движок и протокол — он читает публичное состояние.

## Параметры — токены, не числа в коде
Вид эффекта описывается одним объектом (цвета, толщины, альфы, частоты) в модуле рендера; код отрисовки читает его. Тот же объект показывает лаборатория и хранит каталог `tech/base/vfx-catalog.md`. Правка вида — правка токена.

## В визуальном цикле

**Элемент живёт в лаборатории.** Элемент цикла добавляется сценой в лабораторию эффектов (`/?lab=fx`): детерминированный кадр на настоящем рендере, выбор экрана (телефон, компьютер), время заморожено или идёт, параметры — токен, который можно крутить ползунками.

**Варианты и якоря.** Перед выбором агент готовит 4–6 вариантов на одном контактном листе в размере телефона с подписями параметров. Среди них всегда два якоря: «безопасный» (текущий вид или самый сдержанный) и «заведомо плохой». Если победитель не бьёт безопасный якорь — раунд провален, варианты переделываются. Второй раунд — узкая сетка вокруг победителя.

**Выбирает оператор, парно.** Оператор смотрит варианты на странице просмотра лаборатории (`/?lab=fx&view=review`): все сцены раунда крупно, с увеличением; с компьютера — мелочи, в размере телефона — целые экраны. Картинки в чате — только ориентир. Балльные оценки не используются. Вопрос один: «что из этого выглядит как игра?». Ползунки лаборатории — инструмент агента.

**Критик со свежим контекстом.** До показа оператору варианты смотрит отдельный агент, не писавший код: автоматические проверки из `tech/base/visual-language.md` («Проверка по скриншоту»), затем парное сравнение с перестановкой порядка и список блокеров. Автор не оценивает свой результат словами «выглядит хорошо».

**Фиксация.** Выбранные параметры записываются в токен и каталог; эталонный снимок сцены лаборатории — в визуальную регрессию (`packages/client/test/e2e/visual/`); новое правило, если появилось, — в `visual-language.md`.

## Готовность видимого элемента
Без цикла: оформлен по визуальному языку, проверки по скриншоту телефона и компьютера зелёные, проверен в бою двумя клиентами на экране телефона, движок и протокол не изменились.

В цикле сверх того: есть сцена в лаборатории; прошёл не меньше двух раундов листов, выбор оператора записан в `decisions.md`; критик не нашёл блокеров; токен, каталог и эталон обновлены.
