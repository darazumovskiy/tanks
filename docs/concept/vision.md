# Продукт: онлайн-танки

Браузерная онлайн-игра в танки, вид сверху, бой в реальном времени. Отправная точка — движок и правила боя из `tank-arena` (дуэль ботов 1 на 1): физика и ощущение боя понравились, берём за основу и переделываем под многопользовательскую игру для людей настолько, насколько потребуется.

## Три направления

| Направление | Суть | Статус |
|---|---|---|
| [Сыграть в офисе](office-match.md) | Создал игру → получил ссылку → кинул коллегам в чат → все зашли и бьются. Комната на 10–50 человек, вход через Google | **MVP, приоритет 1** |
| [Бой с ботами](bot-arena.md) | То, что уже есть в `tank-arena`: бой против алгоритма. Плюс возможность написать свой алгоритм и соревноваться с чужими | Приоритет 2 |
| [Ладдер](ladder.md) | Общий игровой мир, разные карты, прокачка танка без дисбаланса | Приоритет 3, отдельный масштаб |

Масштаб направлений разный: комната для коллег — один сервер и один бой; ладдер с общим миром — другая задача по нагрузке, хранению и балансу. Архитектура MVP не должна закрывать путь к ладдеру, но и не строится под него заранее.

## Что фиксировано для всех направлений

- База — браузер. Работа на мобильных (Android, iOS) через браузер обязательна, нативные обёртки — позже.
- Приоритет техники — скорость отклика; всё остальное подчинено ей.
- Сервер авторитарен (см. [ADR архитектура](../adr/architecture.md)): читерство ограничивается конструкцией, античит как отдельная система — не в первой итерации.
