# Сыграть в офисе (MVP)

Один человек создаёт игру и получает уникальную ссылку. Кидает её коллегам в чат. Каждый открывает ссылку в браузере, входит через Google и попадает в бой. Карта создаётся под указанное число участников.

## Сценарий

1. Организатор открывает сайт, входит через Google.
2. Нажимает «Создать игру», указывает число игроков (10–50). Получает ссылку вида `/g/<код>`.
3. Ссылка уходит в чат. Участник открывает её, входит через Google, видит лобби: кто уже в комнате, когда старт.
4. Старт — по кнопке организатора или по заполнению комнаты.
5. Бой идёт на карте, размер которой зависит от числа игроков.
6. По окончании — таблица результатов. Комната живёт, пока организатор не закрыл; можно сыграть ещё раз тем же составом.

## Что берётся из `tank-arena` как отправная точка

Физика танка и снаряда, рикошет, стены, аптечки, характеристики танка (10 очков на броню / двигатель / пушку / перезарядку). Это проверенная база для старта; любая её часть меняется, если так лучше для игры людей.

## Что требует переосмысления

Правила `tank-arena` сделаны под дуэль: раунд 120 секунд, победа по уничтожению соперника, сжимающаяся зона, две симметричные точки появления. Для 10–50 человек нужны:

- режим боя для толпы вместо дуэли до уничтожения;
- карта и точки появления под N игроков, появление в безопасном месте;
- управление человеком: клавиатура и мышь на десктопе, сенсорное управление на мобильном;
- камера за своим танком, карта больше экрана;
- таблица результатов: фраги, урон, точность.

Режим боя и схема управления для MVP выбираются в [задаче bootstrap](../workflow/bootstrap/state.md).

## Границы MVP

Нет: прокачки, рейтингов между играми, ботов в комнате, кастомизации внешнего вида сверх выбора характеристик, античита как отдельной системы, нативных приложений.
