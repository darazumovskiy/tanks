# Сыграть в офисе (MVP)

Один человек создаёт игру и получает уникальную ссылку. Кидает её коллегам в чат. Каждый открывает ссылку в браузере, входит через Google и попадает в бой. Карта — под выбранный размер комнаты.

## Сценарий

1. Организатор открывает сайт, входит через Google.
2. Нажимает «Создать игру», выбирает размер — 10, 30 или 50 мест. Получает ссылку вида `/g/<код>`.
3. Ссылка уходит в чат. Участник открывает её, входит через Google, видит лобби: кто уже в комнате, когда старт.
4. Старт — по кнопке организатора или по заполнению комнаты.
5. Бой идёт по правилам [боя каждый сам за себя](ffa.md) на карте под размер комнаты.
6. По окончании — таблица результатов. Комната живёт, пока организатор не закрыл; можно сыграть ещё раз тем же составом.

## Что берётся из `tank-arena` как отправная точка

Физика танка и снаряда, рикошет, стены, аптечки, характеристики танка (10 очков на броню / двигатель / пушку / перезарядку). Это проверенная база для старта; любая её часть меняется, если так лучше для игры людей.

## Бой

Правила боя для толпы — [ffa.md](ffa.md): матч на время, возрождение, счёт убийств и смертей, зона с внезапной смертью в финале, карты под 10, 30 и 50 мест. Комната по ссылке берёт их как есть; пустые места добираются ботами.

## Границы MVP

Нет: прокачки, рейтингов между играми, кастомизации внешнего вида сверх выбора характеристик, античита как отдельной системы, нативных приложений.
