# Ладдер

Третье направление: общий игровой мир с разными картами, рейтинг игроков, прокачка танка. Отложено до результатов MVP; здесь зафиксировано только намерение и опорные точки.

## Прокачка без дисбаланса

Цель — прогрессия, которая даёт ощущение роста, но не делает ветерана непобедимым для новичка. Опорные примеры из 3D-шутеров, которые это решают: Battlefield (последняя часть) и Sniper Elite — прокачка открывает варианты (оружие, модули, стиль игры), а не поднимает голые числа. Для танков с четырьмя характеристиками на 10 очков естественный аналог — открывать новые раскладки, корпуса и модули с побочными эффектами, а не добавлять очки.

Требуется исследование: как устроена прокачка в указанных играх и в танковых играх (World of Tanks Blitz, Tanki Online, diep.io), что из этого переносится на арену с полной информацией.

## Масштаб

Общий мир — это постоянный онлайн, несколько серверов, хранение прогресса, матчмейкинг по рейтингу, защита от читов. Это другой класс задачи по сравнению с комнатой для коллег; архитектура MVP не строится под ладдер заранее.
