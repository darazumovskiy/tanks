# Мобильная оболочка и установка без магазина

Как превратить браузерный клиент в приложение на Android и iOS и как дать его людям без магазинов. Решения — в `workflow/proto-duel/decisions.md` (2026-10-02).

## Чем заворачивать

| Вариант | Что это | Почему да / нет |
|---|---|---|
| **Capacitor** | Нативный проект под Android и iOS, внутри — системный WebView с нашим веб-клиентом; плагины для полноэкранного режима, ориентации, вибрации | Один код клиента, оба магазина потом доступны, Canvas 2D и WebSocket работают как в браузере. **Выбран** |
| PWA | Та же страница с манифестом и иконкой: «На экран Домой» в Safari и Chrome, запуск на весь экран | Нулевая стоимость, но на Android нет своего установочного файла и управления обновлением; на iOS — единственный бесплатный путь к иконке на экране. Делается как дополнение к Capacitor |
| Tauri 2 mobile | То же, что Capacitor, оболочка на Rust | Мобильная часть молодая, плагинов меньше, выигрыша для WebView-игры нет |
| React Native, Flutter, Unity | Отдельный нативный клиент | Переписывать рендер и предсказание второй раз; движок общий с сервером написан на TypeScript — терять это нельзя |

## Что внутри оболочки

Capacitor умеет два режима: клиент зашит в приложение или приложение открывает адрес сервера (`server.url` в конфигурации). Для пробы выбран второй: приложение ставится один раз, каждая выкладка на сервер обновляет игру на всех телефонах. Цена — без сети приложение не откроется, но игра и так сетевая. Для магазинов этот режим не рекомендуется (Apple требует, чтобы ядро приложения лежало внутри); при выходе в магазины переключаемся на зашитый клиент, конфигурация меняется в одном месте.

## Установка на Android

| Путь | Стоимость | Что нужно пользователю |
|---|---|---|
| **APK на игровом сервере + QR-код на главной странице** | 0 | Сканировать, скачать, один раз разрешить установку «из неизвестных источников». **Выбран** |
| GitHub Releases | 0 | То же, но страница релиза чужая и лишний клик |
| Google Play, внутреннее тестирование | $25 разово | Аккаунт разработчика, проверка Google, список тестировщиков. Позже, с MVP |
| Firebase App Distribution | 0 | Отдельный сервис и приглашения по почте — лишняя сущность для двух телефонов |

APK подписывается своим ключом: Android ставит новую версию поверх старой только при той же подписи. Ключ — в `~/.secrets-tank/`, вне репозитория. Сборка — локально на Mac (Android SDK и JDK 17); запасной путь — GitHub Actions, у публичного репозитория минуты бесплатные.

## Установка на iOS

| Путь | Стоимость | Ограничение |
|---|---|---|
| Xcode на свой iPhone | 0 | Только устройства владельца Apple ID, по кабелю, приложение живёт 7 дней |
| TestFlight | $99 в год (Apple Developer Program) | До 10 000 тестировщиков, сборка живёт 90 дней. Единственный способ поставить на чужой iPhone без магазина |
| PWA «На экран Домой» | 0 | Нет установочного файла, но есть иконка и полный экран |

Для пробы установка на iOS не делается: оба телефона — Android. Capacitor-проект iOS создаётся вместе с Android, собирать его начнём, когда появится iPhone-игрок и решение по аккаунту Apple.

## Что считать «приложением» в пробе

Отличие от сайта в браузере телефона: иконка, полный экран без адресной строки, нет жестов браузера (обновление потягиванием, свайп назад), заблокированная альбомная ориентация, экран не гаснет во время боя. Всё это даёт Capacitor; PWA даёт то же без блокировки ориентации на iOS.
