# Разработка под PlayStation: процесс, железо, технологии

Вопрос (2026-10-04): возможно ли нашими силами выпустить игру на PlayStation — как выкладывать, как отлаживать на своей консоли, подходит ли наш стек. Ответ: возможно как отдельный проект после того, как браузер и телефон станут продуктом; из этого исследования выросли правила «общий пакет не знает платформы» и «браузер на клиенте — заменяемый слой» в [adr/architecture.md](../adr/architecture.md). Источники — публичные: сайт Sony Interactive Entertainment, текст GDPA из материалов суда, документация Godot и W4 Games, Unity, PS5 Developer Wiki, форумы движков; материалы DevNet закрыты.

## Путь до магазина

1. Регистрация на [PlayStation Partners](https://partners.playstation.net/): юрлицо (компания; в Европе принимают и ИП), короткий проектный план — команда, игра, сроки, регионы, отличие. Рассмотрение 2–4 недели, отказ возможен.
2. Подписание GDPA (Global Developer and Publisher Agreement). Открывает DevNet — закрытый сайт с SDK, документацией и формами заявок. Пункт 20.2: материалы Sony нельзя раскрывать третьим лицам без письменного согласия — передача SDK-заголовков в облачную модель формально под этим пунктом; уточнять через Help Center.
3. Регистрация продукта на DevNet, Client ID для входа через PSN.
4. Возрастной рейтинг (PEGI/ESRB) до подачи.
5. Сертификация по TRC (Technical Requirements Checklist): сотни требований — обрыв сети, сон консоли, системные сообщения, сохранения, геймпад. Первая проверка 15–20 рабочих дней; типично 2–3 попытки, 6–8 недель на цикл.
6. Карточка в PlayStation Store — около 4 недель.

Sony берёт 30 % с продаж и внутриигровых покупок. Бесплатные игры допустимы. Каждый патч проходит сертификацию заново (срочные исправления — упрощённо).

Страна: Sony ушла с российского рынка в 2022, PlayStation Store для России закрыт, с мая 2025 блокируются обходные аккаунты. Публичного списка стран для разработчиков нет — он виден внутри формы регистрации при выборе страны. С российским юрлицом партнёрство почти наверняка недоступно; практический путь — юрлицо в поддерживаемой стране.

## Железо и отладка

На розничную PS5 поставить свою сборку нельзя — ни легально, ни «для себя»: режима разработчика у Sony нет (у Xbox есть: Dev Mode на розничной консоли за ~$20). Джейлбрейк зависит от прошивки, нарушает условия Sony и закрывает партнёрство; для продукта — тупик.

Две специальные консоли, обе выдаются только партнёрам:

- DevKit (DFI-D1000) — 32 ГБ памяти вместо 16, подключение к ПК, заливка сборки, отладчик, профилировщик GPU.
- TestKit (DFI-T1000) — розничное железо, принимает неподписанные сборки, TRC-чекер, эмуляция медленного диска, потерь сети, регионов.

С 2022 года новым партнёрам после принятия концепта Sony выдаёт один DevKit и один TestKit бесплатно, в аренду на 2 года; у обоих срок активации, продлеваемый через DevNet.

Рабочее место: Windows, Visual Studio с расширением Sony, компилятор на базе clang, Target Manager для деплоя по сети. Цикл «поправил — собрал — залил — запустил» — минуты.

## Технологии

Сервер подходит как есть: Node, WebSocket, авторитарная симуляция — консоли безразличен другой конец провода.

Клиент не подходит: на PS5 нет браузера для игр (скрытый модальный браузер служит для входа в YouTube и для игр непригоден) и нет WebView, на котором держится мобильная оболочка. Игра — нативное приложение на C/C++ под закрытый SDK и собственный графический API. JIT-компиляция JavaScript системой запрещена.

Варианты:

| Путь | Что делаем | Сложность для агента | Риск |
|---|---|---|---|
| Нативная оболочка + интерпретатор JavaScript | QuickJS (без JIT; портирован на Switch, PS2, PSP; мейнтейнеры считают пригодным для PS5) исполняет `@tanks/shared` без изменений — движок, протокол, предсказание. Переписываются слой рисования (узкий API «спрайт, линия, круг» поверх графики Sony), WebSocket-клиент, ввод с геймпада | XL | SDK под NDA, у агента нет его знаний; вопрос по ИИ-инструментам с материалами Sony |
| Готовый движок | Godot через [W4 Consoles](https://www.w4games.com/w4consoles) ($800/год при выручке до $300k; SDK Sony получаем сами) или Unity (подписка Unity Pro, модули PS5 с DevNet). Клиент переписывается целиком на другом языке; общий движок либо портируется, либо встраивается интерпретатором — тот же первый путь с лишним слоем | XL | Два движка вместо одного |
| Порт-хаус | Seaven Studio, Pineapple Works и подобные портируют и издают за долю или фикс | — | Деньги; игра должна быть законченным продуктом |

Для нашего стека честный путь — первый. Его цена напрямую зависит от того, насколько `shared` и клиентская логика свободны от браузера, — отсюда правила в ADR.

## Онлайн

- Вход для онлайн-функций — только через PSN; вход через Google на консоли не пройдёт. Стандартная схема — привязка PSN-аккаунта к нашему аккаунту.
- PS Plus (платная подписка Sony) обязательна для мультиплеера в платных играх и не нужна в бесплатных. Наша модель «комната коллег по ссылке» означает бесплатную игру на PS5.
- Кросс-плей (PS5 ↔ браузер/телефон) — отдельное одобрение Sony. По документам 2019 года из суда Epic v Apple Sony брала отчисления, если доля выручки с PlayStation ниже доли игрового времени; актуальность публично не подтверждена.
- Чат и ники — родительский контроль и модерация по TRC.
- Свои серверы разрешены.

## Что не удалось выяснить публично

Список поддерживаемых стран (только в форме регистрации), текущая политика кросс-плея, позиция Sony по ИИ-инструментам с материалами SDK — всё это видно после регистрации на DevNet.

## Вывод

PlayStation — цель после того, как браузер и телефон станут продуктом с игроками: девкит выдаётся после принятия концепта, то есть игру нужно убедительно показать до того, как мы увидим железо. Уже сейчас клиент строится так, чтобы консольный порт менял только слой рисования, ввода и сети.
