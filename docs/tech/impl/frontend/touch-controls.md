# Сенсорное управление

Два плавающих стика на холсте боя: левая половина экрана — корпус, правая — башня и огонь. Сервер и протокол не меняются: стики переводятся в тот же `Action` (`throttle`, `turn`, `turretTurn`, `isFiring`), что и клавиатура с мышью, и уходят в предсказание и на сервер тем же путём.

## Поведение

**Плавающий стик.** Круга на экране заранее нет. Палец касается своей половины — появляется основание стика: в точке касания, но не ближе к краю экрана, чем радиус плюс 12 % радиуса (`EDGE_GAP_RATIO`), иначе ручку нельзя было бы довести до упора к краю; отклонение считается от основания. Палец ведёт — ручка смещается от основания. Отклонение больше радиуса стика обрезается до радиуса. Палец отпущен — стик исчезает. Два пальца одновременно — два независимых стика по `pointerId`.

**Левый стик — курс корпуса.** Направление стика на экране — желаемый курс танка (экран и поле боя сонаправлены: камера не двигается, поле целиком в кадре). Клиент каждый тик берёт курс танка из предсказания и считает `turn` так, чтобы довернуть до желаемого курса за тик, но не быстрее `turnRate`; `throttle` — отклонение стика, умноженное на косинус угла доворота: ехать прямо — полный газ, развернуться — крутиться на месте.

**Задний ход.** Если желаемый курс расходится с курсом танка больше чем на 110°, танк переходит на задний ход: доворачивает кормой и едет назад. Обратно на передний ход — когда расхождение меньше 70°. Разрыв между порогами нужен, чтобы на границе танк не метался между режимами.

**Правый стик — башня и огонь.** Направление стика — желаемый угол башни, `turretTurn` считается как для мыши. Отклонение ≥ 85 % радиуса — `isFiring = true`, пока палец у края: движок стреляет по мере перезарядки, как при зажатой кнопке мыши. Отпущенный стик башню не трогает. Короткое касание правой половины (меньше 200 мс, сдвиг меньше мёртвой зоны) — один тик `isFiring = true`: выстрел туда, куда башня уже смотрит.

**Мёртвая зона**, **радиус** и **кольцо огня** — настройки (`settings.ts`: умолчания, подобранные Димой на телефоне, — 0,07; 40 CSS-px; 0,89), меняются в панели в бою и хранятся на устройстве. Стик берёт значения в момент касания — смена настроек не дёргает уже зажатый стик. Мёртвая зона рисуется пунктирным кругом внутри стика.

**Совместная работа с клавиатурой и мышью.** Активный левый стик заменяет клавиши корпуса, активный правый — мышь; без стиков всё как раньше. Чтобы касание не превращалось браузером в движение и клик мыши, `pointerdown` касания гасится `preventDefault`. Все указатели — мышь, палец, стилус — читаются через Pointer Events, мышь отличается по `pointerType`.

**Телефон в портретной ориентации** — поверх боя подсказка «Поверни телефон горизонтально»; в альбомной подсказка исчезает.

**Фон и потеря фокуса.** `blur`, `pagehide`, `visibilitychange: hidden` сбрасывают зажатые стики и ожидающий тап: касание может не дойти до завершения, а сервер со своей стороны останавливает замолчавший танк через полсекунды.

**Браузерные жесты.** Долгое нажатие не выделяет текст и не открывает меню: `user-select: none`, `-webkit-touch-callout: none`, `touch-action: none`. Прокрутка страницы запрещена только на странице боя (`body.duel`: `overflow: hidden`, `overscroll-behavior: none`); главная страница с формой прокручивается, чтобы кнопка была достижима на низком экране.

## Ключевые файлы

| Файл | Роль |
|---|---|
| `packages/client/src/steering.ts` | Чистые функции: `steerHull(stick, deadZone, heading, turnRate, isReversing)` → `throttle`, `turn`, новый режим заднего хода; `aimTurret(angle, turret)` → `turretTurn`; пороги заднего хода |
| `packages/client/src/settings.ts` | Настройки ощущения с умолчаниями, проверкой диапазонов и хранением в `localStorage` (`tanks.settings`) |
| `packages/client/src/settingsPanel.ts` | Панель в бою (шестерёнка в углу или клавиша O): ползунки по таблице `NUMERIC_FIELDS`, график кадров, сброс |
| `packages/client/src/touch.ts` | `TouchSticks`: слушает Pointer Events касаний на холсте, ведёт до двух стиков по половинам экрана, отдаёт их состояние для чтения ввода и рисования, фиксирует тап правой половины |
| `packages/client/src/input.ts` | `InputReader`: объединяет клавиатуру, мышь и стики в один `Action` на тик |
| `packages/client/src/render/renderer.ts` | Рисует стики в экранных координатах поверх кадра: основание, ручка, у правого — кольцо огня, подсвеченное при стрельбе |
| `packages/client/src/game.ts` | Передаёт состояние стиков в рендер |
| `packages/client/src/main.ts` | Подсказка про ориентацию: `matchMedia('(orientation: portrait) and (pointer: coarse)')` |

### Клиент — автоматические тесты (Vitest, окружение `happy-dom`)

`steering.test.ts` — перевод стика в действие:

| Сценарий | Ожидание |
|---|---|
| Стик по курсу танка, полное отклонение | `throttle` = 1, `turn` = 0 |
| Стик под 90° к курсу | `throttle` = 0, `turn` = ±1 в сторону стика |
| Стик чуть левее курса (меньше одного тика поворота) | `turn` дробный, ровно доводящий до курса за тик |
| Стик на 45° при половинном отклонении | `throttle` = 0,5 · cos 45°, `turn` = 1 |
| Стик против курса (180°) из переднего хода | режим — задний ход, `throttle` < 0, `turn` = 0 |
| Стик под 100° из переднего хода | остаёмся на переднем ходу (ниже порога входа 110°) |
| Стик под 80° из заднего хода | остаёмся на заднем ходу (выше порога выхода 70°) |
| Стик под 60° из заднего хода | переход на передний ход |
| Отклонение внутри мёртвой зоны | `throttle` = 0, `turn` = 0, режим не меняется |

| Башня: желаемый угол далеко | `turretTurn` = ±1 |
| Башня: желаемый угол в пределах тика | дробный `turretTurn` |
