# Клиент дуэли

Браузерный клиент: страница создания дуэли и страница боя. Код — `packages/client/src/`, сборка Vite, рендер Canvas 2D.

| Файл | Роль |
|---|---|
| `main.ts` | Маршрут: `/` — форма (ник, характеристики, «Создать дуэль» → `/d/<случайный код>`), `/d/<код>` — бой. Ник и характеристики — в `localStorage`. `window.tanksGame` — доступ для сквозных тестов |
| `game.ts` | Связка: сеть → предсказание → ввод → рендер; цикл кадров с фиксированным шагом ввода 30/с; оверлеи «ждём соперника», отсчёт, итог раунда |
| `net.ts` | WebSocket, кодек протокола, `Ping`/`Pong` раз в секунду → сглаженная задержка туда-обратно |
| `prediction.ts` | Своя копия движка: ввод применяется сразу, очередь неподтверждённых команд, при снимке — состояние сервера плюс переигрывание очереди; чужой танк и снаряды — интерполяция между двумя снимками с отставанием на два тика |
| `input.ts` | WASD / стрелки — корпус; мышь — башня (скорость поворота, доводящая башню до курсора за тик, не быстрее предела движка); левая кнопка или пробел — выстрел |
| `render.ts` | Поле 1600×900 вписывается в окно; стены, зона, аптечки, снаряды, танки с полосой здоровья и ником, счёт, HUD |

## Что показывает HUD

Задержка туда-обратно, тик сервера, число неподтверждённых команд (при 30 тиках/с равно задержке в тиках), поправка предсказания в пикселях на последнем снимке (0,0 — клиент и сервер считают одинаково), кадров в секунду.

## Ограничения пробы

Нет сенсорного ввода и звука; поле целиком на экране, камера не нужна; при уходе соперника экран возвращается к ожиданию с той же ссылкой. Фоновая вкладка не шлёт ввод: браузер останавливает цикл кадров.
