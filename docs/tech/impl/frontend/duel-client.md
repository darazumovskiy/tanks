# Клиент дуэли

Браузерный клиент: страница создания дуэли и страница боя. Код — `packages/client/src/`, сборка Vite, рендер Canvas 2D, оформление и звук перенесены из `tank-arena/viewer/`.

| Файл | Роль |
|---|---|
| `main.ts` | Маршрут: `/` — форма (ник, характеристики, «Создать дуэль» → `/d/<случайный код>`), `/d/<код>` — бой. Ник и характеристики — в `localStorage`. `window.tanksGame` — доступ для сквозных тестов |
| `game.ts` | Связка: сеть → предсказание → ввод → эффекты → звук → рендер; цикл кадров с фиксированным шагом ввода 30/с; отсчёт и итог раунда рисуются на холсте, DOM-оверлей — только для «ждём соперника» и ошибок |
| `net.ts` | WebSocket, кодек протокола, `Ping`/`Pong` раз в секунду → сглаженная задержка туда-обратно |
| `prediction.ts` | Своя копия движка: ввод применяется сразу, очередь неподтверждённых команд, при снимке — состояние сервера плюс переигрывание очереди. Свои снаряды рисуются из предсказания, чужой танк и чужие снаряды — интерполяция между двумя снимками с отставанием на два тика |
| `input.ts` | WASD / стрелки — корпус; мышь — башня (скорость поворота, доводящая башню до курсора за тик, не быстрее предела движка); левая кнопка или пробел — выстрел; M — звук. Касания — стики из `touch.ts` через `steering.ts`, см. [touch-controls.md](touch-controls.md) |
| `sfx.ts` | Синтезированные звуки Web Audio: выстрел, рикошет, попадание, взрыв, перехват, аптечка, отсчёт, тревога зоны. Контекст открывается первым нажатием |
| `render/view.ts` | Логический кадр 1920×1080, поле со смещением (160, 170), шрифты, цвета сторон, утилиты |
| `render/art.ts` | Спрайты танков из SVG (64×64, носом вправо), окрашенные в цвет стороны; отрисовка с тенью, вспышкой, отдачей, «подбитым» видом |
| `render/floor.ts` | Пол карты, рисуется один раз: текстура, сетка, площадки появления, стены с тенью, фаской и полосой |
| `render/effects.ts` | Частицы (искры, дым, вспышки, кольца, огонь, обломки), следы гусениц и подпалины на отдельном холсте, хвосты и свечение снарядов, всплывающие цифры урона, объявления («ПЕРВАЯ КРОВЬ», «САМ СЕБЯ!», «ЗОНА СУЖАЕТСЯ»), тряска и вспышка экрана |
| `render/renderer.ts` | Сборка кадра: пол → следы → аптечки → зона → танки → снаряды → частицы → метки → надписи; панели игроков сверху (имя, характеристики, здоровье с «призраком» потерь, счёт), таймер, отсчёт, баннер конца раунда, строка отладки |

## Откуда берутся эффекты

Все эффекты и звуки запускаются событиями из снимков сервера (`SnapshotEvent`): направление и признаки события лежат в `dx`, `dy`, `flags`. Локальное предсказание эффектов не порождает, поэтому дублей нет; задержка эффекта относительно собственного действия — половина задержки сети.

## Что показывает строка отладки

Задержка туда-обратно, тик сервера, число неподтверждённых команд (при 30 тиках/с равно задержке в тиках), поправка предсказания в пикселях на последнем снимке (0,0 — клиент и сервер считают одинаково), кадров в секунду.

## Ограничения пробы

Поле целиком на экране, камера не нужна; при уходе соперника экран возвращается к ожиданию с той же ссылкой. Фоновая вкладка не шлёт ввод: браузер останавливает цикл кадров. Шрифты Russo One и Inter грузятся с Google Fonts, без сети — системные.
