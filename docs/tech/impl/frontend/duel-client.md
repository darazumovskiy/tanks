# Клиент дуэли

Браузерный клиент: страница создания дуэли и страница боя. Код — `packages/client/src/`, сборка Vite, рендер Canvas 2D, оформление и звук перенесены из `tank-arena/viewer/`.

| Файл | Роль |
|---|---|
| `main.ts` | Маршрут: `/` — форма (ник, характеристики, «Создать дуэль» → `/d/<случайный код>`, «Против манекена» → `/d/bot<случайный код>`, см. [duel-server.md](../backend/duel-server.md)) и блок с QR-кодом Android-приложения, если сервер раздаёт APK ([android-app.md](../infra/android-app.md)); `/d/<код>` — бой, `body.duel` запрещает прокрутку, подсказка про ориентацию, панель настроек ([touch-controls.md](touch-controls.md)). Ник и характеристики — в `localStorage`. `window.tanksGame` — доступ для сквозных тестов |
| `game.ts` | Связка: сеть → предсказание → ввод → эффекты → звук → рендер; цикл кадров с фиксированным шагом ввода 30/с; отсчёт и итог раунда рисуются на холсте, DOM-оверлей — только для «ждём соперника» и ошибок |
| `net.ts` | WebSocket, кодек протокола, `Ping`/`Pong` раз в секунду → сглаженная задержка туда-обратно. Разрыв не по нашей воле — переподключение с паузой 1, 2, 4, 5, 5… с и повторный вход в ту же комнату; возврат вкладки или приложения на экран — попытка сразу; ошибка от сервера (комната полна, версия протокола) — окончательна. Тесты — `net.test.ts` с поддельным сокетом |
| `prediction.ts` | Своя копия движка: ввод применяется сразу, очередь неподтверждённых команд, при снимке — состояние сервера плюс переигрывание очереди. Свои снаряды рисуются из предсказания, чужой танк и чужие снаряды — интерполяция между двумя снимками с отставанием на два тика |
| `input.ts` | WASD / стрелки — корпус; мышь — башня (скорость поворота, доводящая башню до курсора за тик, не быстрее предела движка); левая кнопка или пробел — выстрел; M — звук. Касания — стики из `touch.ts` через `steering.ts`, см. [touch-controls.md](touch-controls.md) |
| `sfx.ts` | Синтезированные звуки Web Audio: выстрел, рикошет, попадание, взрыв, перехват, аптечка, отсчёт, тревога зоны. Контекст открывается первым нажатием |
| `render/camera.ts` | Камера за своим танком: окно фиксированной высоты, прижатие к краям поля, перевод координат, метка за кадром — [mobile-screen.md](mobile-screen.md) |
| `render/view.ts` | Шрифты, цвета сторон, утилиты |
| `render/art.ts` | Спрайты танков из SVG (сетка 64×64, растр 256 px, носом вправо), окрашенные в цвет стороны; отрисовка с тенью, вспышкой, отдачей, «подбитым» видом |
| `render/floor.ts` | Пол карты в двойном разрешении, рисуется один раз: текстура, сетка, площадки появления, стены с тенью, фаской и полосой |
| `render/effects.ts` | Частицы (искры, дым, вспышки, кольца, огонь, обломки), следы гусениц и подпалины на отдельном холсте, хвосты и свечение снарядов, всплывающие цифры урона, объявления («ПЕРВАЯ КРОВЬ», «САМ СЕБЯ!», «ЗОНА СУЖАЕТСЯ»), тряска и вспышка экрана |
| `render/renderer.ts` | Сборка кадра: мир через камеру (пол → следы → аптечки → зона → танки → снаряды → частицы → метки), затем в экранных координатах — панели по углам (свой слева), таймер и счёт, стрелка на противника за кадром, объявления, отсчёт, баннер конца раунда, строка отладки, стики |

## Откуда берутся эффекты

Все эффекты и звуки запускаются событиями из снимков сервера (`SnapshotEvent`): направление и признаки события лежат в `dx`, `dy`, `flags`. Локальное предсказание эффектов не порождает, поэтому дублей нет; задержка эффекта относительно собственного действия — половина задержки сети.

## Что показывает строка отладки

Четыре числа, каждое отвечает на свой вопрос. **К/с** — успевает ли устройство рисовать (норма — частота экрана). **Худший кадр, мс** — максимум длительности кадра за последнюю секунду: были ли рывки (16 — идеально, 33 — заметно, 50+ — рывок); среднее к/с их прячет. **Задержка, мс** — туда-обратно до сервера. **Поправка, px** — насколько сервер поправил свой танк на последнем снимке (0,0 — клиент и сервер считают одинаково; большие числа — дёргает не отрисовка, а расхождение с сервером). Тик сервера и число неподтверждённых команд — в `window.tanksGame.debugState()`.

## Ограничения пробы

При уходе соперника экран возвращается к ожиданию с той же ссылкой. При разрыве связи (фон приложения, выкладка сервера) клиент переподключается сам, раунд начинается заново; счёт комнаты сохраняется, если соперник остался. Фоновая вкладка не шлёт ввод: браузер останавливает цикл кадров. Шрифты Russo One и Inter грузятся с Google Fonts, без сети — системные.
