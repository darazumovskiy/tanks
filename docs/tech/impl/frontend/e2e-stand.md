# Стенд сквозных тестов

Вся игра целиком: собранные сервер и клиент, два настоящих браузера заходят по ссылке и играют. Ловит то, что не видят тесты сервера и модульные тесты клиента: рассинхрон состояния между раундами, переподключение, поведение после ухода соперника.

Запуск: `npm run test:e2e` — собирает пакеты и гоняет Playwright (Chromium без окна). Код — `packages/client/test/e2e/`, настройка — `playwright.config.ts` в корне.

## Устройство

| Файл | Роль |
|---|---|
| `server.ts` | Запускает `packages/server/dist/main.js` на свободном порту с `STATIC_ROOT` из `packages/client/dist` и дополнительным окружением из конструктора (серверные тумблеры вроде `WALL_SLIDE`), читает порт из вывода; умеет остановить и поднять заново на том же порту |
| `player.ts` | Игрок в браузере: открывает `/d/<код>` (с `query` — строкой запроса, например `?admin=1`) со своими ником, характеристиками и, если заданы, настройками (`settings` → `tanks.settings`) в `localStorage`, читает `window.tanksGame.debugState()`, едет к точке клавишами (`driveTo`) или доворачивает на курс и держит газ (`driveOnHeading`), наводит башню мышью по формуле камеры из `debugState().camera`, открывает панель настроек клавишей и читает подписи флажков (`settingsCheckLabels`); с `isTouch` — контекст телефона 844×390 с эмуляцией касаний (`pointer: coarse`), касание кнопки авто-огня, касание-протяжка через `Input.dispatchTouchEvent` протокола отладки (`touchDrag`) |
| `duel.spec.ts` | Сценарии на сервере с умолчаниями |
| `wallSlide.spec.ts` | Сценарий на отдельном процессе сервера с `WALL_SLIDE=1` — [round-rules.md](../backend/round-rules.md) |

Танк ведётся клавишами как человеком: `A`/`D` — доворот корпуса до курса на точку, `W` — газ, когда курс сошёлся; башня — положение мыши, выстрел — зажатая кнопка. Убийство ставится на карте «Полигон»: стрелок (орудие 5, перезарядка 5) едет на верхнюю полосу `y = 100` и стреляет вдоль неё по мишени (броня 0), которая стоит на той же полосе у своего края — между ними стен нет.

## План тестирования

| Сценарий | Ожидание |
|---|---|
| Два браузера заходят по одной ссылке | у обоих `debugState()` не `null`, стороны 0 и 1; `W` у первого двигает его танк, второй видит это движение |
| Два раунда подряд | стрелок убивает мишень на авто-огне; у стрелка попап «ПОБЕДА!», у мишени «ПОРАЖЕНИЕ», кнопка «В меню» ведёт на `/`; приходит второй раунд, попап скрыт, авто-огонь выключен (`roundIndex` 1, карта 1); ввод в новом раунде двигает танк — проверка бага со счётчиком команд между раундами |
| Соперник ушёл и вернулся | у оставшегося оверлей «Ждём соперника», `debugState()` — `null`; соперник открывает ссылку снова — раунд начинается, оба едут |
| Сервер перезапущен под открытыми страницами | оверлей «Связь потеряна…», затем оба клиента переподключаются сами, раунд начинается, ввод работает |
| Телефон: кнопка авто-огня | кнопка видна игроку с касанием и скрыта на компьютере; касание включает (`isAutoFiring` true), второй игрок видит снаряды; второе касание выключает, снаряды заканчиваются и за время дольше перезарядки новых нет |
| Телефон: автоведение башни | игрок с касанием ничего не трогает, компьютерный едет через проход «Полигона» в точку вне оси появления внутри кадра телефона — башня телефона сходится к углу на него (`isAutoAiming` true); башня компьютерного игрока не сдвинулась (`isAutoAiming` false); протяжка правой половины вниз уводит башню к π/2, через 0,25 с после отпускания она ещё там, затем возвращается к противнику |
| Предохранитель от своего рикошета | игрок с `hasRicochetGuard: true` наводит башню мышью перпендикулярно к ближнему краю поля и зажимает кнопку — за время дольше перезарядки снарядов нет ни у него, ни у соперника, `isShotGuarded` true; наводит по диагонали вверх-вправо — снаряды появляются, `isShotGuarded` false |
| Линия выстрела | игрок с `hasAimLine` и `hasAutoAim` и соперник встают на верхнюю полосу «Полигона» — `debugState().aimLine.state` у первого становится `onTarget`, `isAutoAiming` true, `isReturning` false; соперник уезжает за стену (330, 160) в (1350, 700) — `none`, линия есть; у соперника без флага `aimLine` — `null` |
| Огонь по цели | телефон с `?admin=1`, `hasZoneFire` и `hasAutoAim` стоит на точке появления; компьютер прячется за стену (330, 160) в (480, 200) через (1150, 450) и (900, 200) — башня телефона на нём (`isAutoAiming` true); телефон держит палец на правой половине 2 с — снарядов нет ни у кого, `isZoneFiring` false; компьютер выезжает на ось появления (480, 450) — `isZoneFiring` true, снаряды видны обоим |
| Админ-режим | страница с `?admin=1` — в панели настроек (клавиша O) есть флажок «Подсказка упреждения»; у игрока без параметра — нет |
| Кнопка «⌂» в бою | адрес становится `/`, видна главная |
| Комната с манекеном | по ссылке `/d/bot01…` раунд стартует сразу, человек на стороне 1, имя соперника «Манекен», он двигается |
| Бот с главной | в выпадающем списке уровень 10, «В бой» → адрес `/d/bot10…`, бой начинается, соперник «ПАРАЛЛАКС-ASTRA» двигается |
| Скольжение вдоль стен (`wallSlide.spec.ts`, сервер с `WALL_SLIDE=1`) | `debugState().rules.hasWallSlide` true у обоих; первый едет на верхнюю полосу, доворачивает на ≈ 26° к краю и держит газ — у края пять замеров подряд: `me.speed ≥ 150`, `correctionPx ≤ 2`; второй видит, как противник проехал вдоль края больше 50 px |
| Фоновая вкладка | вручную на устройстве (`knowledge/device-testing.md`): браузер без окна не останавливает таймеры фоновой вкладки |
