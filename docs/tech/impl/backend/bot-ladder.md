# Лестница ботов

Десять уровней сложности серверного бота для дуэли «против бота». Заполнены уровни 1, 2, 3 и 10; остальные появятся как ограничения одного алгоритма по итогам калибровки игрой. Код — `packages/server/src/bots/`, общий контракт клиента и сервера — `packages/shared/src/protocol/botRoom.ts`.

| Уровень | Имя на экране | Характеристики | Что делает |
|---|---|---|---|
| 1 | Манекен | 3/3/2/2 | Каждые 1–2 с случайный курс на 60 % газа, башня на противника вдвое медленнее предела с шумом ±0,35 рад, выстрел с вероятностью 0,3 в секунду при наведении в 0,3 рад |
| 2 | Карусель | 4/2/2/2 | Спарринг-бот «Манекен» из `tank-arena`: едет на 70 % газа по синусоиде, башня на текущее положение противника, огонь при ошибке меньше 0,2 рад каждую перезарядку. Стен при езде не учитывает; в отличие от оригинала не стреляет, когда линия от дула до противника перекрыта стеной, — иначе расстреливает себя рикошетами и проигрывает манекену |
| 3 | Охотник | 3/3/2/2 | Спарринг-бот «Охотник» из `tank-arena`: путь по сетке 25 px (поиск в ширину), упреждение по скорости цели, огонь только при чистой линии до точки упреждения, уход от летящих пуль перпендикулярно, аптечки при здоровье ниже 60 %, возврат в зону, круг вокруг цели на 300–330 px |
| 10 | ПАРАЛЛАКС-ASTRA | 2/1/2/5 | Бот участника GPT-6 Astra из турнира `tank-arena`, файл без изменений. Не предполагается выигрываемым: тренажёр, нанесённый урон — результат |

## Код комнаты

`bot` + две цифры уровня + код: `bot01k7m2px`, `bot10k7m2px`. `botRoomCode(level, suffix)` собирает, `botLevelOf(code)` разбирает: `null` для кода без префикса, без двух цифр и для уровня, которого нет в `BOT_LEVELS`. Код с префиксом `bot` и без известного уровня сервер отклоняет как неверный код комнаты (`Error BadMessage`). Список уровней с именами и описаниями — `BOT_LEVEL_INFO`; клиент строит из него выбор на главной, сервер — таблицу мозгов (`Record<BotLevel, …>`, полнота проверяется компилятором).

## Бот — подключение

Бот живёт внутри процесса как `Connection` (`bots/arenaBot.ts`): занимает место 0 при создании комнаты, получает те же сообщения, что игрок, и отвечает вводом через своё `Seat` с теми же проверками. Поля боя он не видит — восстанавливает его из протокола: на `RoundStart` создаёт собственный раунд движком (`createRound` по индексу карты и характеристикам обоих), на каждом `Snapshot` переписывает в него танки, снаряды (урон — по характеристикам владельца), аптечки, радиус зоны, тик и строит `BotView` — тот же вид, что получает участник `tank-arena`. Снимок с `isOver` пропускается. Номер команды растёт на всё время подключения.

Мозг — `BotBrain`: `stats`, необязательный `init(view)` на старте раунда, `tick(view) → Action`. Мозги уровней 1–3 написаны на TypeScript с состоянием в полях экземпляра (`dummy.ts`, `carousel.ts`, `hunter.ts`); проверка линии огня сквозь стены общая — `sight.ts`. Уровень 10 — `scriptBot.ts`: файл `packages/server/bots/parallax/bot.js` читается один раз при старте процесса, `export default` заменяется на `return`, текст оборачивается в функцию и компилируется `node:vm`; каждый вызов функции даёт свежий экземпляр модуля со своими переменными — комнаты не делят состояние. Переходник переводит `BotView` в формат арены (`alive`, `mine`, `active`) и ответ `{ fire }` — в `Action` через `sanitizeAction`. Файл — доверенный контент из репозитория, лимит времени на ход не вводится (замер: 0,125 мс в среднем, максимум 2 мс при тике 33 мс).

## Файлы

| Файл | Роль |
|---|---|
| `shared/src/protocol/botRoom.ts` | `BOT_ROOM_PREFIX`, `BOT_LEVELS`, `BOT_LEVEL_INFO`, `botRoomCode`, `botLevelOf`, `isBotRoomCode` |
| `server/src/bots/arenaBot.ts` | `BotBrain`, `ArenaBot` — подключение с зеркалом раунда |
| `server/src/bots/dummy.ts`, `carousel.ts`, `hunter.ts` | Мозги уровней 1–3 |
| `server/src/bots/sight.ts` | Пересечение отрезка со стенами — линия огня и видимость |
| `server/src/bots/scriptBot.ts` | Загрузка файла бота арены и переходник вида |
| `server/src/bots/ladder.ts` | Уровень → мозг и характеристики; `createBot` |
| `server/bots/parallax/` | Файл бота Астры как есть и заметка о происхождении |
| `client/src/main.ts`, `index.html` | Выбор уровня на главной, запоминается на устройстве; кнопка «Против бота» |

## План тестирования

Сервер — через сокет (`app.test.ts`, `duel.test.ts`):

| Сценарий | Ожидание |
|---|---|
| Код `bot01…` | бот «Манекен» на стороне 0, человек на стороне 1, `RoundStart` сразу, бот двигается и стреляет |
| Коды `bot02…`, `bot03…`, `bot10…` | в `RoundStart` имена «Карусель», «Охотник», «ПАРАЛЛАКС-ASTRA» и характеристики уровня; бот двигается (стоящий за стеной человек — не цель, выстрел не требуется) |
| Коды `botabc`, `bot07abc`, `bot99abc`, `bot1abc` | `Error BadMessage`, соединение закрыто, комната не создана |
| Третий в комнату с ботом | `RoomFull` |
| Человек ушёл | бот снят, комната удалена; повторный вход сажает бота заново |
| Скриптовый человек против уровня 3 | раунд доигрывается до конца, стартует следующий с тем же `gameId` |

Стенд «бот против бота» (`ladder.test.ts`, комната без сокета, два бота на двух местах, тик в цикле): пары 2 против 1, 3 против 2, 10 против 3 — четыре карты, каждая с обеих сторон (две рассадки). Ожидание: старший уровень выигрывает не меньше шести раундов из восьми и больше, чем младший. Это же проверяет зеркало раунда: бот с неверными стенами или аптечками не выигрывает. Замер 2026-10-04: 2 против 1 — 7:1, 3 против 2 и 10 против 3 — 8:0; весь стенд меньше секунды.

Мозг Охотника — на крафтовых видах (`hunter.test.ts`), как движок: ситуации, до которых стенд доходит не в каждом прогоне, задаются видом напрямую — аптечка при низком здоровье, уход в сжавшуюся зону вместо перестрелки, цель внутри сплошной стены (пути нет — едет прямо на цель).

Протокол (`botRoom.test.ts`): код собирается и разбирается туда-обратно для каждого уровня; у каждого уровня есть имя и описание; `null` для кода без префикса, с одной цифрой, с неизвестным уровнем.

Сквозные (`test:e2e`):

| Сценарий | Ожидание |
|---|---|
| Главная: выбран уровень 10, «Против бота» | адрес `/d/bot10…`, бой начинается, имя соперника «ПАРАЛЛАКС-ASTRA», соперник двигается |
| Комната `bot01…` по ссылке | раунд стартует сразу, человек на стороне 1, манекен двигается |

Вручную агентом в браузере (2026-10-04, пройдено): главная с выбором уровня на компьютере и на размере телефона, уровень запоминается; бой с уровнями 2, 3, 10 — имя в панели, Карусель кружит у точки появления и не стреляет сквозь стену, Охотник идёт по пути вокруг стен и попадает, ПАРАЛЛАКС-ASTRA убивает стоящего игрока за первый раунд. Калибровка ощущений — игра Димы на телефоне.
