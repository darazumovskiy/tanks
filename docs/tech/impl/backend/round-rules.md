# Правила раунда и скольжение вдоль стен

Правила раунда — набор включаемых правил движка, одинаковый на сервере, у ботов и в предсказании клиента. Первое правило — скольжение вдоль стен, включается серверным тумблером `WALL_SLIDE=1`. Код — `packages/shared/src/engine/round.ts` (`RoundRules`, `DEFAULT_RULES`, `resolveTankWalls`), `packages/shared/src/engine/constants.ts` (константы стен), `packages/shared/src/protocol/codec.ts` (`rulesToFlags`, `rulesFromFlags`).

## Правила как механизм

`RoundRules { hasWallSlide: boolean }` — часть состояния раунда: `createRound(mapIndex, setups, rules)` кладёт копию в `round.rules`, `stepRound` читает их оттуда. Умолчание `DEFAULT_RULES` — всё выключено; с ним движок повторяет оригинал `tank-arena` бит в бит, эталон детерминизма не перегенерируется.

Источник правил — сервер: переменная окружения `WALL_SLIDE=1` в `main.ts` → `AppOptions.rules` → `RoomManager` → `Room`; комната создаёт каждый раунд с этими правилами и кладёт их в `RoundStart.rules`. Клиент создаёт раунд предсказания с правилами из `RoundStart` — иначе предсказание у стен расходилось бы с сервером на каждом тике касания. Бот (`bots/arenaBot.ts`) создаёт зеркало раунда с теми же правилами. Стенд «бот против бота» (`ladder.test.ts`) — правила по умолчанию.

## Скольжение вдоль стен

Без правила касание стены или края поля на каждом тике умножает скорость на `WALL_HIT_SPEED_FACTOR = 0.6`; танк, едущий в стену под углом, касается её каждый тик, и скорость сходится к равновесию с разгоном — около 20 единиц в секунду, «залипание». Геометрически скольжение есть и так: выталкивание по нормали оставляет касательную часть смещения; мешает только штраф.

С правилом штраф зависит от угла встречи. За тик касания скорость умножается на

`1 − WALL_SLIDE_PENALTY · |n·h|³`, `WALL_SLIDE_PENALTY = 0.25`,

где `n` — единичная нормаль контакта (`circleRect` для стены карты; для края поля — ось сработавшего зажима), `h` — единичный вектор курса танка. Лоб в стену — 0,75; 60° к стене — 0,84; 45° — 0,91; 30° — 0,97. При нескольких контактах за тик (угол стен, стена у края) берётся наибольший |n·h| — самый лобовой контакт.

Событие `bump` (звук удара на клиенте): без правила — при любом касании на скорости выше `WALL_BUMP_MIN_SPEED = 60`; с правилом — когда касание за тик отняло больше `WALL_BUMP_MIN_DROP = 25` скорости. В установившемся скольжении касание отнимает ровно разгон тика (14), поэтому скольжение под любым углом молчит; удары звучат только пока танк гасит лишнюю скорость после входа в стену.

Измерения при газе в пол на «Полигоне» (разгон `ACCEL · DT` = 14 за тик, предел 176 при двигателе 3, вход в верхний край на 176), 90 тиков:

| Угол к стене | Скорость в равновесии | Удары `bump` | Без правила |
|---|---|---|---|
| 90° (лоб) | 42 | 4 на входе, дальше тишина | 21, 4 удара |
| 60° | 72 | 2 на входе | 21, 4 удара |
| 45° | 144 | 0 | 21, 4 удара |
| 30° | 170 | 0 | 21, 4 удара |
| 20° | 174 | 0 | 21, 4 удара |

## Протокол

`PROTOCOL_VERSION = 4`. `RoundStart` после `score` несёт `rules` — один байт флагов, бит 0 — скольжение (`rulesToFlags`, `rulesFromFlags`). Клиент версии 3 получает `Error BadProtocolVersion` и просьбу обновить страницу.

## Журнал

Строка `game start room= p0= p1= rules=<число битов>` — те же биты, что в `RoundStart`. Анализатор `packages/analysis` незнакомые поля пропускает.

## Тумблер на бою

`WALL_SLIDE=1` в окружении сервиса `tanks.service` рядом с `LOG_DIR`; без переменной правило выключено. Как включить — [deploy-proto.md](../infra/deploy-proto.md).
