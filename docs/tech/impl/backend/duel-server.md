# Сервер дуэли

Один процесс Node: HTTP для клиента и проверки здоровья, WebSocket на `/ws`, комнаты по коду, общий тик 30/с. Код — `packages/server/src/`.

| Файл | Роль |
|---|---|
| `app.ts` | HTTP-сервер, апгрейд WebSocket, разбор сообщений, цикл тика с компенсацией дрейфа таймера, `/healthz` |
| `room.ts` | Комната: два места, фазы `waiting → countdown → fight → roundEnd → …`, снимки. Вход даёт `Seat` — ввод, ping и уход игрока идут через него; бой (`Duel`) существует только при двух игроках. Сокетов не знает — работает через `Connection.send` |
| `roomManager.ts` | Комнаты процесса, соединение → место и комната, удаление пустых; код `bot<уровень>…` — комната с ботом на месте 0 |
| `bots/` | Лестница ботов: бот как `Connection` внутри процесса, мозги уровней, загрузка файла бота Астры — [bot-ladder.md](bot-ladder.md) |
| `static.ts` | Раздача собранного клиента; `/` и `/d/<код>` отдают `index.html`; путь запроса для всех HTTP-веток |
| `gameLog.ts` | Журнал игры в файлы `LOG_DIR/<gameId>.log` с буфером и сбросом по таймеру; приёмщик строк клиента `POST /log` — [game-log.md](game-log.md) |
| `main.ts` | Запуск: `PORT`, `STATIC_ROOT`, `APK_PATH`, `LOG_DIR` |

## Комната

Код комнаты — `[a-z0-9]{3,16}` из ссылки `/d/<код>`; комната создаётся при первом входе и удаляется, когда оба вышли. Третьему входящему — `Error RoomFull`. Ник обрезается до 16 символов, пустой — «Игрок»; неверные характеристики заменяются на 3/3/2/2.

Фазы: пока игрок один — `waiting`, снимки не идут. Два игрока — `RoundStart` и отсчёт 90 тиков, в отсчёте ввод игнорируется, снимки идут. Бой — до конца раунда по движку. После конца — 90 тиков паузы, счёт победителю, следующий раунд на следующей карте (`roundPlan`). Уход игрока в любой фазе — раунд сбрасывается, комната в `waiting`, счёт сохраняется.

## Бот

Код комнаты `bot` + две цифры уровня + код (кнопка «Против бота» на главной) создаёт комнату, в которой первым игроком уже сидит бот выбранного уровня со своим именем и характеристиками — [bot-ladder.md](bot-ladder.md). Человек получает сторону 1, раунд стартует сразу. Ввод бота проходит те же проверки комнаты, что и ввод игрока. Код с префиксом `bot` без известного уровня — неверный код комнаты. Второму человеку в такую комнату — `RoomFull`. Ушёл человек — бот снимается, комната удаляется; вход по той же ссылке снова сажает бота. Случайность манекена подменяема (`AppOptions.random`) — тесты детерминированы.

## Тик

Каждый тик: для каждого игрока берётся последняя пришедшая команда (остальные за тик теряются), её `seq` становится `ackSeq`; без новой команды повторяется предыдущая, но не дольше `INPUT_TIMEOUT_TICKS` (15 тиков, полсекунды) — замолчавший клиент (приложение в фоне, зависло) получает покой, а не вечную езду и стрельбу по последней команде. Шаг движка; снимок каждому игроку со своим `ackSeq` и `gameTick` — тиком с создания дуэли. Таймер — `setTimeout` от расписания, не от фактического времени; при отставании больше пяти тиков расписание сбрасывается; опоздание тика к расписанию передаётся в комнаты и попадает в журнал игры. `/healthz` отдаёт число комнат, соединений, тик и максимальную длительность тика за последнюю секунду.

Дуэль (`Duel`) при создании получает `gameId` — 4 знака без похожих символов; он уходит клиентам в `RoundStart` и именует файл журнала. Строки журнала сервера — в [game-log.md](game-log.md).

## План тестирования

Только через точки входа: HTTP и WebSocket (`test/client.ts` — клиент на том же кодеке). Скриптовые игроки шлют ввод на каждый снимок, как настоящий клиент. Покрытие `packages/server/src` без `main.ts` — 100 % по всем метрикам, порог в `vitest.config.ts`. Тики в тестах — 1–4 мс, отсчёт и пауза — 2–3 тика.

`app.test.ts` — HTTP, вход, одиночные действия:

| Сценарий | Ожидание |
|---|---|
| `/healthz` | 200, число комнат и соединений |

| APK: есть файл, `HEAD`, файла нет, маршрут не настроен | 200 с заголовками, длина без тела, 404, 404 |
| WebSocket не на `/ws` | соединение отклонено |
| Битый кадр WebSocket (без маски) | сервер закрывает соединение, `/healthz` живой |
| `createApp()` без параметров, `close()` без `listen()` | работает с умолчаниями, закрывается без ошибки |
| Два игрока входят | стороны 0 и 1, `RoomState`, `RoundStart`, одна комната |
| Повторный `Join` из комнаты | игнорируется: ни ошибки, ни второго `Welcome` |
| Третий в комнату, чужая версия протокола, неверный код, мусор, серверное сообщение от клиента | `Error` с кодом и закрытие |

| Боты (`bot01…`, `bot02…`, `bot03…`, `bot10…`, коды без уровня) | см. план в [bot-ladder.md](bot-ladder.md) |

| Устаревший и слишком частый ввод | отброшен; через секунду лимит сброшен и ввод снова принимается |
